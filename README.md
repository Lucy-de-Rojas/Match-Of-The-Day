# Match-Of-The-Day

Regex matching game in single HTML file

2027 is the Year of Regex! Match of the Day turns learning regular expressions into a daily puzzle, with 2,027 challenges from beginner to advanced. Type a pattern and see exactly what it matches. It all runs offline in a single HTML file.
